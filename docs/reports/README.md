# Bosqich hisobotlari

Har bosqich tugaganda shu papkaga `bosqich-N.md` yoziladi (`_shablon.md` bo'yicha). Hisobot
foydalanuvchi bosqichni qabul qilishi uchun yoziladi: qilingan ish, tekshiruv natijalari, ochiq
qolganlar.

Qoidalar:

- Faqat haqiqatda bo'lgan narsa yoziladi. Ishga tushirilmagan tekshiruv "bajarilmadi" deb yoziladi,
  yiqilgan test chiqishi bilan keltiriladi.
- Bosqich davomida qabul qilingan har qaror `docs/PLAN.md` ning 22-bo'limiga ham yoziladi. Hisobotda
  unga havola beriladi.
- Rejadan chetga chiqish (qo'shilgan, olib tashlangan yoki keyinga qoldirilgan narsa) alohida bo'limda
  sababi bilan yoziladi.
- Hisobot yozilgach, PLAN 18-bo'limdagi jadvalda holat va hisobotga havola yangilanadi.
